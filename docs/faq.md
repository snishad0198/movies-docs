### Q3: Why is the project split into separate repositories?
- [movies-frontend](https://github.com/snishad0198/movies-frontend): Lightweight Next.js client, optimized for 1-click deployment on Vercel or Netlify.
- [movies-backend](https://github.com/snishad0198/movies-backend): Next.js API & Admin Console with Prisma ORM and MySQL, designed for VPS, Docker, or Railway.
- [movies-docs](https://github.com/snishad0198/movies-docs): Pure documentation hub with hosting guides, live demos, and policy terms.
- [movies-web](https://github.com/snishad0198/movies-web): All-in-one monorepo with 1-command full-stack runner (`npm run dev`).

---

### Q4: Where does the movie data and stream come from?
- Movie and series metadata (posters, backdrops, cast, ratings, synopsis) is synced dynamically from **TMDB (The Movie Database)**.
- Streaming nodes use multi-server embed players with fallback support.
- Direct downloads are proxied through fast multi-quality servers.
